# My City: Inside

City builder + life simulation. Игрок строит город, а затем может зайти внутрь
любого здания и наблюдать за жизнью его жителей.

* Движок: **Godot 4.x** (проект проверен на 4.4-stable)
* Язык: **GDScript**
* Платформа: **Android**, с полноценным запуском на Windows / Linux / macOS для отладки
* Стиль: 2D изометрия (2:1), плейсхолдерная графика на этапе MVP

## Запуск

Открыть папку `game/` как проект в Godot 4 и нажать F5.
Главная сцена — `res://scenes/boot/boot.tscn`.

## Self-test архитектуры

```bash
godot --headless --path game -- --selftest
```

Прогоняет 12 проверок (сервисы, изометрия, стены/двери, сериализация мира,
шаблоны контента, часы, экономика, шина событий, сейв/лоад, планировщик
симуляции) и возвращает ненулевой код выхода при любой ошибке. Годится как
проверка в CI.

Тот же отчёт виден на экране при обычном запуске игры.
